# 빅테크 투자 모니터: 안드로이드 PWA + 주간 자동 갱신 예시

## 지금 사용하기
- 단독 HTML (`index.html`)을 안드로이드 Chrome에서 열 수 있습니다. 주가 자동 갱신은 **없고**, 내장 스냅샷은 2026-11-16입니다.
- 휴대폰 화면 너비에 맞게 그래프를 자동으로 그립니다. 탭: 2024년~, 2025년~, 2026년~, 2026.07~+전망.
- 2025.01.01은 미국 거래 휴장일 → 2025.01.02 **종가**를 100으로 사용합니다.

## 주간 자동 갱신 및 앱처럼 설치하기
1. GitHub 계정을 만들고 새 repository(예: `bigtech-monitor`)를 생성합니다. **공개 repository는 내용이 공개**됩니다. 민감한 계좌정보는 업로드하지 마세요.
2. 이 ZIP의 **폴더 안 파일들**(`index.html`, `updates.json`, `manifest.webmanifest`, `icon-*.png`, `sw.js`, `update_prices.py`, `.github/workflows/refresh.yml`, `.nojekyll`)을 repository 최상위에 업로드합니다.
3. GitHub > repository > **Settings → Pages → Build and deployment → Source: GitHub Actions**를 설정합니다.
4. **Actions** 탭에서 `Weekly stock refresh and publish` 워크플로를 수동으로 1회 실행하거나 `main`에 push하면 배포됩니다.
5. 사이트 주소(`https://사용자명.github.io/bigtech-monitor/`)를 안드로이드 Chrome에서 열고 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
6. 이후 기본값은 **매주 토요일 오전 8시 17분(KST)** 주가 확인 → `updates.json` 게시 → 앱 실행 시 새 종가 반영입니다.

## 주의
- `yfinance`는 **공식 유료 시세 API가 아닙니다**. 차단, 데이터 누락 또는 지연으로 갱신 실패할 수 있습니다. 이 경우 마지막 성공 데이터가 계속 표시됩니다.
- GitHub Actions의 예약 실행도 지연되거나 누락될 수 있으므로, 항상 상단 `데이터:` 날짜를 확인하세요.
- 주간 자동화는 **주가 7개 종가만** 갱신합니다. PER, 고점의 공식 기록, 매수/매도 추천, 거시 이벤트 일정과 전망 가정은 별도 월간 검토가 필요합니다.
- 단독 HTML의 CSV 수동 업데이트는 사용 브라우저 저장소에만 반영될 수 있습니다. 다른 기기의 데이터에 자동으로 동기화되지 않습니다.
- GitHub Pages 사이트는 공개로 노출됩니다. 비공개 보관이 필요하면 인증 지원 호스팅을 별도로 사용해야 합니다.

## 기준점
- `2024-01-02`, `2025-01-02`, `2026-01-02`, `2026-07-01`: 고정.
- 순수 주가 종가/가격지수 기준이며 배당 제외. 이 페이지의 과거 월말 값은 기존 대시보드 스냅샷을 보존한 것입니다.
